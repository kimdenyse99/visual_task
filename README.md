# visual_task
Extension of the existing MXBI marmoset behavioral platform for eye-tracking experiments: includes adapting current tasks and developing new visual detection/discrimination paradigms while building a modular eye-tracking system for acquisition, pupil/corneal-reflection tracking, gaze estimation, recording, and integration through a simple SDK

Adapted from the 2ac-vocalization-discrimination task from the mxbi repository and designed to work with mxbi-flow and the relevant configurations.
